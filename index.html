JSON → Google Sheets Converter

Paste a JSON (e.g. an API response) and get a table ready for Google Sheets, Excel or CSV. Nothing leaves your browser.

Result:

📋 How to use:

  1. Click "Copy for Sheets"
  2. Open your Google Sheet
  3. Select cell A1
  4. Paste (Ctrl+V or Cmd+V)

The result will appear here

💡 Supported JSON shapes:

1. Array of objects

[
  { "date": "2024-03-25", "price": 100 },
  { "date": "2024-03-26", "price": 150 }
]

2. Parallel arrays

{
  "date": ["2024-03-25", "2024-03-26"],
  "price": [100, 150]
}

3. Wrapped in items[].value

{
  "items": [{
    "value": {
      "date": ["2024-03-25"],
      "price": [100]
    }
  }]
}

Nested objects become dotted columns (guest.country). Non-array fields next to parallel arrays (metadata, status, …) are ignored.
