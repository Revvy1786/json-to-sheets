📋 Come usare:

  1. Clicca su "Copia per Sheets"
  2. Apri il tuo Google Sheet
  3. Seleziona la cella A1
  4. Incolla (Ctrl+V o Cmd+V)

💡 Formati JSON supportati:

Formato 1: Con items array

{
  "items": [{
    "value": {
      "date": ["2024-03-25", "2024-03-26"],
      "price": [100, 150],
      "propertyId": [101, 102]
    }
  }]
}

Formato 2: Con value diretto

{
  "value": {
    "date": ["2024-03-25", "2024-03-26"],
    "price": [100, 150],
    "propertyId": [101, 102]
  }
}

Il tool ignora automaticamente tutti gli altri campi nel JSON (metadata, spec, status, ecc.)
